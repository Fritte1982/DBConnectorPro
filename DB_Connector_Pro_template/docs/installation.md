# Installation

## Stable release

To install DB Connector Pro, run this command in your terminal:

```sh
uv add DB_Connector_Pro
```

Or if you prefer to use `pip`:

```sh
pip install DB_Connector_Pro
```

## From source

The source files for DB Connector Pro can be downloaded from the [Github repo](https://github.com/Fritte1982/DB_Connector_Pro).

You can either clone the public repository:

```sh
git clone git://github.com/Fritte1982/DB_Connector_Pro
```

Or download the [tarball](https://github.com/Fritte1982/DB_Connector_Pro/tarball/master):

```sh
curl -OJL https://github.com/Fritte1982/DB_Connector_Pro/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd DB_Connector_Pro
uv pip install .
```
