### 📘 Offizielle Python-Dokumentation

* **[Packaging Python Projects](https://packaging.python.org/tutorials/packaging-projects/)**
  Dieses Tutorial führt dich Schritt für Schritt durch den Prozess, ein einfaches Python-Projekt zu verpacken. Es zeigt dir, wie du die notwendigen Dateien und die Struktur erstellst, um das Paket zu bauen und es auf dem Python Package Index (PyPI) hochzuladen.

* **[Installing Packages](https://packaging.python.org/tutorials/installing-packages/)**
  Hier erfährst du, wie du Python-Pakete installierst, sowohl aus dem Internet als auch lokal von deinem Computer.

### 🛠️ Praktische Anleitungen

* **[How to create a Python library](https://medium.com/analytics-vidhya/how-to-create-a-python-library-7d5aea80cc3f)**

  Wenn du dein eigenes Repository für Python-Pakete hosten möchtest, zeigt dir dieser Leitfaden, wie du entweder ein Softwarepaket wie `devpi` verwendest oder einfach die richtige Verzeichnisstruktur erstellst und einen Webserver nutzt, der statische Dateien bereitstellt.
